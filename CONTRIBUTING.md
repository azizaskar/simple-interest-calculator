
# Contributing to Simple Interest Calculator

Thank you for your interest in contributing to this project!

## Contributions

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

We appreciate all contributions that help improve this project.

## How to Contribute

1. Fork the repository on GitHub.
2. Clone your fork to your local computer.
3. Create a new branch for your changes.
4. Make your changes and test them.
5. Stage your changes using git add.
6. Commit your changes using git commit.
7. Push your changes to your GitHub fork.
8. Create a pull request.

## Reporting Bugs

If you find a bug, please create a GitHub Issue.

Include:
- A clear description of the bug.
- Steps to reproduce the problem.
- The expected result.
- The actual result.

## Bug Fixes

Bug fixes are always welcome.

Please explain what problem you fixed and how you tested your changes.

## Documentation Improvements

Documentation improvements are welcome.

You can improve the README.md file, fix spelling mistakes, and add useful examples.

## Enhancements and Ideas

We welcome new features, suggestions, and ideas that can make the Simple Interest Calculator better.

## Code Guidelines

- Write clean and readable Bash code.
- Use meaningful variable names.
- Add comments where necessary.
- Test your changes before submitting.
- Keep the code simple.

## Pull Requests

When submitting a pull request:

1. Describe your changes clearly.
2. Explain why the changes are needed.
3. Make sure your code works correctly.
4. Wait for the project maintainer to review your pull request.

## Code of Conduct

All contributors must follow the CODE_OF_CONDUCT.md file.
