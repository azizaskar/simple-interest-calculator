
# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project!

## Contributions

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork this repository.
2. Clone your fork to your local computer.
3. Create a new branch for your changes.
4. Make your improvements or fix bugs.
5. Commit your changes with a clear message.
6. Push your branch to GitHub.
7. Create a pull request.

## Reporting Bugs

If you find a bug, please open a GitHub issue and describe the problem.

## Code Quality

Keep your code simple, readable, and well documented.

## Pull Requests

All pull requests will be reviewed before merging.

Thank you for helping improve this project!
