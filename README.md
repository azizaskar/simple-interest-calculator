
# Simple Interest Calculator

## Project Description

This project is a simple interest calculator written in Bash.
It calculates simple interest using the principal amount,
annual interest rate, and time period in years.

## Project Details

Project Name: Simple Interest Calculator

Programming Language: Bash Shell Script

License: Apache License 2.0

## Input

- p: Principal amount
- r: Annual rate of interest (%)
- t: Time period in years

## Output

Simple Interest = (p * r * t) / 100

## Example

Principal = 1000
Rate = 5
Time = 2

Simple Interest = 100

## How to Run

1. Clone the GitHub repository.
2. Open a terminal.
3. Navigate to the project directory.
4. Run the following command:

   bash simple-interest.sh

5. Enter the principal, rate, and time.
